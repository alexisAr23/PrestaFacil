# PrestaFácil

**Sistema web de gestión de préstamos de objetos personales.**

## Descripción

PrestaFácil es una aplicación web diseñada para administrar el registro de objetos personales, controlar los préstamos realizados a otras personas, gestionar las devoluciones y consultar el historial de movimientos.

## Objetivo

Facilitar el control y seguimiento de los objetos prestados mediante una plataforma centralizada.

## Módulos principales

- **Gestión de artículos:** registro y consulta de objetos.
- **Gestión de préstamos:** creación y consulta de préstamos pendientes.
- **Devoluciones e historial:** registro de devoluciones y consulta de movimientos.
- **Autenticación:** inicio de sesión y protección de las rutas internas (propuesta adicional pendiente de aprobación).

## Tecnologías

- Frontend: Next.js, React y TypeScript.
- Backend: NestJS.
- ORM: Prisma.
- Base de datos: PostgreSQL.
